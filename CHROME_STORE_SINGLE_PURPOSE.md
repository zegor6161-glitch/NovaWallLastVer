# Chrome Web Store Single Purpose

Terenval Wallet has one clear purpose: provide a non-custodial cryptocurrency wallet in the browser for Ethereum, selected Ethereum Layer 2 networks, custom EVM networks, and Bitcoin.

Functions within that purpose:

- create or import wallet accounts and manage keys locally;
- display public addresses, balances, assets, and transaction state;
- connect to compatible dApps;
- let users approve or reject account access and signature requests;
- prepare, sign locally, and broadcast user-approved transactions;
- configure a custom EVM network;
- optionally send minimized product analytics after explicit consent.

The submitted release excludes unrelated promotions and non-core swap, hardware-wallet, and remote-backup features.
